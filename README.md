# BIM Tasks

نظام إدارة المهام والموظفين — بيم دمشق.

- **الكود فقط.** قاعدة البيانات، مرفقات الموظفين، ملف `.env` والنسخ الاحتياطية **ما بتنرفع هون أبداً** (شوف `.gitignore`).
- كل تعديل محفوظ بتاريخه بقسم **Commits**.
- التحديثات بتوصل للسيرفر كملف تثبيت (`deploy/`) بينشغّل كمسؤول.
- الصلاحيات: `app/access.py` — وبالموقع صفحة «جدول الصلاحيات».
- تفاصيل السيرفر وطريقة التحديث: `CLAUDE.md`. ملاحظات التركيب القديمة: `README_AR.txt`.
